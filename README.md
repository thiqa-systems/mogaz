# موجز الصباح

تطبيق ويب قابل للتثبيت (PWA) يعرض أهم أخبار مصر والعالم والاقتصاد والتكنولوجيا من مصادر متعددة، ويتحدّث آلياً كل 10 دقائق.

## كيف يعمل
- `.github/workflows/update.yml` يشغّل `scripts/update.mjs` كل 10 دقائق على GitHub Actions.
- السكربت يقرأ خلاصات RSS المذكورة في `feeds.json`، يحذف المكرر والقديم، يوازن بين المصادر، ويكتب `data.json`.
- `index.html` يعرض `data.json`. GitHub Pages يستضيف التطبيق مجاناً.

## التشغيل لأول مرة
1. Settings → Pages → Source: Deploy from a branch → `main` / root.
2. Actions → «تحديث الأخبار» → Run workflow (للتجربة فوراً).

## التعديل
- إضافة أو حذف مصدر أخبار: عدّل `feeds.json` فقط.
- الأسعار (الدولار، الذهب، البورصة، النفط...) في `scripts/markets.mjs` وتتحدّث تلقائياً. الذهب المحلي تقديري من السعر العالمي وسعر الدولار.
- مؤشرات مصر الشهرية (التضخم، الفائدة) في `indicators.json` وتُحدَّث يدوياً عند صدور أرقام جديدة.
- الخلاصات التي فشلت في آخر تشغيل تظهر في `data.json` تحت `failed`.
- الذكاء الاصطناعي: أضف في Settings → Secrets and variables → Actions سرّين باسم `GEMINI_API_KEY` و `GEMINI_API_KEY_2` (من Google AI Studio). الثاني احتياطي عند نفاد حصة الأول.
- يُستدعى Gemini فقط عند ظهور عناوين جديدة، وبحد أقصى مرة كل 20 دقيقة، لتوفير الحصة المجانية.
- لتغيير النموذج: أضف Variable باسم `GEMINI_MODEL`. حالة آخر استدعاء وأي خطأ تظهر في `data.json` تحت `ai`.
